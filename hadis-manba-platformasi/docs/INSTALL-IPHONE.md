# iPhone / iPad

**Talab:** iOS/iPadOS 16.4+ (paket ochish uchun `DecompressionStream` kerak), Safari.

1. Safari'da Hadith Library saytini oching (HTTPS manzil; nashr qilingach README'ga yoziladi).
2. Ulashish (↑) → **Add to Home Screen** → **Add**. Bosh ekrandagi belgidan oching.
3. **Kitoblar** → kerakli kitob yoki sharhni **O'rnatish**. "Oflayn tayyor" chiqishini kuting.
   - Ekran qulflansa yoki aloqa uzilsa yuklash to'xtashi mumkin — fon rejimida tugashi kafolatlanmaydi. Qayta **O'rnatish** ni bosing; eski kutubxona buzilmaydi.
4. Fayl bilan: `.hmz`ni Files ilovasiga saqlang → **Kitoblar → Fayldan import**.
5. **Paketlar → Doimiy saqlashni so'rash.** Muhim: bosh ekran ilovasi va Safari'dagi sayt ma'lumotni **alohida** saqlaydi; Safari ma'lumotlari tozalansa yoki ilova o'chirilsa paketlar yo'qolishi mumkin. Shaxsiy qaydlarni **Qaydlar → eksport** bilan zaxiralang.
6. Internetsiz sinash: Parvoz rejimini yoqing → ilovani yoping va qayta oching → qidiring.

**Holat:** real iPhone'da sinalmagan. CI/headless Chromium sinovi iPhone Home Screen sinovi emas — `PLATFORM-TEST-MATRIX.md`.
