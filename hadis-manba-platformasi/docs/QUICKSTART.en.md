# Quick start (one page)

## 1. Open the app
- **iPhone / iPad:** open the Hadith Library address in **Safari** → Share (↑) → **Add to Home Screen** → Add.
- **Android:** open it in **Chrome** → ⋮ → **Install app**.
- **Windows / Mac:** open it in **Chrome or Edge** → click the **install** icon in the address bar (Mac Safari 17+: File → Add to Dock).

Address: <https://nbeast19.github.io/vositalar/hadis-manba-platformasi/web/> (packages: [GitHub Release](https://github.com/Nbeast19/vositalar/releases/tag/hadis-manba-paketlar-v1)).

## 2. Install a book
1. Open **Library**. Find a book by Arabic, English or transliterated name.
2. Press the book. You see **Main text** and **Commentaries**, each with its size and licence.
3. Press **Install book only** — or tick commentaries and press **Install book + selected commentaries**. Packages already installed are not downloaded again.
4. Wait for **Offline ready**. If something fails, your library is unchanged — try again.

## 3. Read and search (no internet needed)
- **Search:** type an Arabic phrase. “Ignore vowel marks” finds it with or without ḥarakāt; the original voweled text is shown.
- **Find by number:** choose the book, type the number (and volume if needed). If several candidates match, you choose — none is picked automatically.
- On a hadith page, **Installed commentaries** lists the passages for *this* hadith. In a commentary, **Back to the hadith** returns.

## 4. Copy, bookmark, back up
- **Copy citation with source** gives the work, number, edition, page, exact quotation, status and source ID.
- ☆ bookmarks and notes stay on this device and survive updates. Use **Notes → Export** and **My books → Save as file** to back up. Ask for **persistent storage** in *My books*.

## 5. Status words
verified · limited · conflict · not found · not reviewed — “limited” or “not reviewed” is **not** firm evidence. A search match is not an identification of a hadith.
