# التثبيت والاستعمال بلا إنترنت — ويندوز، ماك، آيفون، أندرويد، لينكس

لا حساب، ولا بايثون، ولا ذكاء اصطناعي. بعد التثبيت تعمل الكتب التي ثبّتّها بلا إنترنت.
**حالة الاختبار:** هذه الخطوات تنجح في اختبارات آلية بمتصفح كروميوم (بالعربية والإنجليزية، بعرض 1280 و390 بكسل، بلا إنترنت)، ولم **تُختبر بعد على أجهزة حقيقية**؛ انظر [PLATFORM-TEST-MATRIX.md](../PLATFORM-TEST-MATRIX.md).

## آيفون / آيباد (iOS 16.4 أو أحدث)
1. افتح عنوان مكتبة الحديث في **سفاري**.
2. مشاركة (↑) ← **إضافة إلى الشاشة الرئيسية** ← **إضافة**. افتحه من أيقونة الشاشة الرئيسية.
3. **المكتبة** ← اختر كتابًا ← **تثبيت الكتاب وحده** أو **تثبيت الكتاب مع الشروح المختارة** ← انتظر **جاهز بلا إنترنت**.
4. أبقِ الشاشة مفتوحة أثناء التنزيل؛ قد يوقف iOS التنزيل في الخلفية. إن انقطع فاضغط التثبيت مجددًا — لا يضيع شيء.
5. **كتبي ← طلب التخزين الدائم.** تطبيق الشاشة الرئيسية وسفاري يحفظان البيانات منفصلين؛ حذف بيانات سفاري أو التطبيق قد يحذف الكتب. صدّر الملاحظات (**الملاحظات ← تصدير**) واحفظ ملفات الحزم (**كتبي ← حفظ كملف**).
6. للتحقق: فعّل وضع الطيران، أغلق التطبيق وافتحه، ثم ابحث.

## أندرويد (كروم 103 أو أحدث)
1. افتح العنوان في **كروم** ← ⋮ ← **تثبيت التطبيق**.
2. ثبّت الكتب من **المكتبة** وانتظر **جاهز بلا إنترنت**.
3. للتثبيت من ملف: **المكتبة ← التثبيت من ملف**.
4. اطلب التخزين الدائم واحفظ نسخة من الملاحظات.

## ويندوز (كروم أو إيدج 103+)
1. افتح العنوان ← اضغط أيقونة **التثبيت** في شريط العنوان ← يظهر التطبيق في قائمة ابدأ.
2. ثبّت الكتب من **المكتبة**.

## ماك
- سفاري 17+: ملف ← **إضافة إلى Dock**. كروم/إيدج: أيقونة **التثبيت** في شريط العنوان.
- ثبّت الكتب من **المكتبة**.

## لينكس
كروم/كروميوم ← أيقونة التثبيت. للمتقدم: `pip install ".[mcp]"` ثم `hadis-manba serve --web web`.
