# Hadith Library | مكتبة الحديث — book and commentary downloads

**[Open the app / افتح التطبيق](https://nbeast19.github.io/vositalar/hadis-manba-platformasi/web/)** — the easiest way: choose a book in the app and press *Install*. It works offline afterwards.

**Downloading a file here instead?** A `.hmz` file is a library package, not a document to open. Open the app → *My library* → *Install from a file* and choose the `.hmz` file. ملف ‎.hmz حزمة مكتبة: افتح التطبيق ← مكتبتي ← التثبيت من ملف.
