Help

  1. Open the app and the Library.
  2. Choose a book.
  3. Install the book only, or tick commentaries and install them together.
  4. Search, or open the book's contents.
  5. On a hadith, open an installed commentary; “Back to the hadith” returns.
  6. Copy the citation with its source.

After installation books work without internet. Only installed packages are available offline. Browsers can delete stored data — keep the package files and export your notes.

Status words: verified, limited, conflict, not found, not reviewed. “Limited” or “not reviewed” is not firm evidence.

AI connection is optional and only on a computer (MCP server). The app works fully without it.
