Install on your device

iPhone / iPad

Open the app in Safari (iOS 16.4 or newer) → Share → Add to Home Screen → Add. Open it from the Home Screen, then install books in the Library.

Android

Open the app in Chrome → ⋮ menu → Install app (or Add to Home screen). Then install books in the Library.

Windows

Open the app in Chrome or Edge → click the install icon in the address bar. Then install books in the Library.

Mac

Safari 17+: File → Add to Dock. Chrome/Edge: install icon in the address bar. Then install books in the Library.

Linux

Chrome/Chromium → install icon in the address bar. Advanced users can also use the command-line tool.

These steps were tested in an automated Chromium browser only; they have not yet been tested on real iPhone, Android, Windows or Mac devices.
